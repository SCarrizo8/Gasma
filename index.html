Una base prolija para seguir creciendo

Este proyecto no solo debe verse bien: también debe estar bien construido. Por eso el enfoque combina HTML semántico, Bootstrap para el layout y SCSS modular para un mantenimiento más profesional.

  • HTML limpio y fácil de leer
  • Bootstrap para maquetado
  • SCSS con variables, mixins, nesting y @extend
  • Diseño adaptable a mobile, tablet y desktop
